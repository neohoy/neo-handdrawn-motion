# 歌词转画面：每首歌重新画

这个技能固定的是歌词版式（见 [歌词版式](歌词版式.md)）。画面每首歌都从头设计：画什么人、什么东西、什么地方，全部从这首歌的歌词里读出来，再一件一件画成这首歌自己的素材。

`examples/风吹新竹/` 里的人物和道具只用来看画法，不能搬进新歌。新歌哪怕也唱到海、窗和回家，也要按新歌的歌词重新设计。

## 第一步：读整首，定全片

先把整首歌词读完，回答下面几件事，写进 `设计/意象表.md` 的“全片”一栏。

- **一句话主题**：这首歌在讲谁、经历了什么。《风吹新竹》是“一个在新竹长大的孩子，风把他吹向海边、吹向很多城市，最后吹回家”。
- **谁在唱**：第一人称“我”，还是“我们”？唱的人多大？从歌词里的场景推年龄和身份，比如“下课的晚餐”说明是学生，“简报和预算”说明已经工作。
- **时间跨度**：一个下午、一个季节，还是十几年。跨度长的歌，同一个角色要有不同年龄的画法。
- **地点**：歌词点名的地方，比如东门城、城隍庙、园区、海边公路；也包括暗示的地方，比如“宿舍门前”。
- **母题**：全片反复出现、能带着画面往前走的东西。《风吹新竹》是风，于是定下“风永远从右往左吹”，头发、围巾、树叶、行人都朝同一个方向。别的歌可能是雨、一盏灯、一条路、一列火车。母题定了，它的方向、颜色和出现方式就全片统一。
- **颜色节奏**：按段落排底色，相邻段落拉开，副歌用最饱和的颜色，开头和结尾可以回到纸色。

## 第二步：逐句拆

每一句歌词拆成五样东西，填进意象表的“逐句”一栏。

1. **看得见的名词**：东西、建筑、食物、交通工具、天气。
2. **地点**。
3. **动作**：谁在做什么，往哪个方向。
4. **时间**：傍晚、深夜、凌晨、下课后。
5. **情绪词和抽象词**：牵挂、长大、答案、不慌张。

画面里至少要有一样东西直接来自这句歌词。抽象词找一个能画出来的替身。

| 歌词里的抽象词 | 《风吹新竹》里画成了什么 |
|---|---|
| 长大 | 门框当身高尺，两个人在强拍上从小孩长成大人，铅笔画刻度 |
| 答案（咖啡杯映着凌晨的答案） | 咖啡面上映着凌晨三点的钟 |
| 牵挂 | 一块挂在线上、来回晃的吊牌 |
| 不慌张（在浪声里练习不慌张） | 大浪随拍打过来，坐在海堤上的两个人没有动 |
| 很远很满（风把笑声吹得很远很满） | 笑出来的字从嘴边飞走，越飞越大 |

不要用和歌词无关的通用画面：一颗心、一个地球、一束光线、抽象几何。画面越具体，越像这首歌。

## 第三步：设计角色和道具

- **主角**：从“谁在唱”推出年龄、发型、衣服和一个标志色。标志色全片不变，长大以后换衣服也保留它。《风吹新竹》的主角是白衬衫配黄围巾，黄色同时是风和光的颜色。
- **其他角色**：只设计歌词里真的出现的人。“我们”就画两个人，并给两人各自一个能分清的特征（发型、颜色、发夹）。
- **道具**：歌词里点名的东西都列出来。地方特产和地标要先查资料确认长什么样，查不到确切资料就不画。《风吹新竹》原想画海边风车，没查到就放弃了。
- **同一角色的不同状态**：表情、手势、年龄、正面和侧面，都作为同一个素材函数的参数，不要另起一个长得不一样的人。

画法用 `scripts/kit/draw.py` 里的基础件：参数化的人（正面、侧面走路、背影，发型和衣服颜色可调）、天气、植物和简单建筑。歌词点名的具体东西（庙、车票、某种食物、某座建筑）一律在 `scripts/assets/` 里新画。

## 第四步：画出来，先看素材表

1. 每件素材写成一个函数，放在工程的 `scripts/assets/*.py`，在文件末尾的 `SHEET` 列出要展示的样子。
2. 运行 `asset_sheet.py`，把这首歌的全部角色和道具拼成素材表 `设计/素材表.png`。
3. 自己逐张看：
   - 比例对不对；
   - 墨线有没有断；
   - 角色在不同状态下还是不是同一个人；
   - 是否一眼能认出是歌词里的那样东西。
4. 素材表和分镜一起给用户看，这是第一个检查点。用户提出的改动先改素材，再进镜头。

## 第五步：画面和歌词放在一起

每句歌词选一个版式组件，并让它和画面里的东西呼应。

| 画面里有 | 歌词放在 |
|---|---|
| 街、店、市场 | 竖排招牌 `sign`、吊牌 `hang_tag` |
| 庙、门、过年 | 对联 `couplet` |
| 小吃、教室、咖啡馆 | 黑板菜单 `chalk_board` |
| 公路、旅途、距离 | 路牌 `road_sign` |
| 夜空、星星、许愿 | 流星写字 `sky_write` |
| 笑声、喊声、被风吹走的话 | 飞字 `spill`，或对话框 `bubble` |
| 副歌钩子、一个关键字（家、长大、名字） | 砸拍大字 `slam` |
| 安静的一句 | 纸标签 `label_line` |
| 一段的收尾句 | 黑缎带 `ribbon_line` |
