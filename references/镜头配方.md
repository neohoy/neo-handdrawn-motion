# 镜头配方与画法工具

## 镜头配方

下面是《风吹新竹》里验证过的镜头套路。套路可以搬，画面内容不能搬：用到哪一条，都换成新歌歌词里的人、物和地点。括号里是示例文件（在 `examples/风吹新竹/`）或当时工程里的镜头号。

| 配方 | 什么时候用 | 怎么做 |
|---|---|---|
| **标题页** | 前奏 | 母题先出场（《风吹新竹》是一道铅笔风线）→ 环境按强拍长出来 → 主角入场 → 歌名 `slam` 逐字砸下 → `seal` 印章 → 署名写出 → 转场（s01） |
| **一景两组** | 一个镜头唱两句 | 每句一组画面，组之间用 `band_through` 切换（`full_s02.py`） |
| **歌词写在物件上** | 所有唱段 | 用 `typo.py` 的组件，让载体和画面呼应，对照表见 [歌词转画面](歌词转画面.md)（s02/s03/s05/s07） |
| **随时间变化的环境** | 黄昏、深夜 | 太阳缓缓下沉、影子拉长、挂钟飞转、台历翻到第二天、天色按拍轮换（`full_s02.py`、`full_s17.py`） |
| **经过即点亮** | 有人走过、骑过 | 先算出人物经过每个物件的时间，再吸附到下一个半拍，让灯笼或窗户逐个亮起（`full_s02.py`、`build_f3.py`） |
| **沿曲线行驶** | 骑车、机车、风筝 | 在 Python 里沿贝塞尔曲线取约 10 个关键帧（位置、朝向、远小近大），逐段补间 `transform` 属性（`build_f2.py`、s04） |
| **四格漫画** | 主歌里一连串很短的句子 | 2×2 格子，一句一格，句首前 0.28 秒砸进来；每格一个 `clipPath`（`full_s11.py`） |
| **分屏** | 两个人在两个地方 | 左右两个 `clipPath`，中间一条锯齿墨线，纸飞机或虚线把两边连起来（s18） |
| **东西落进容器** | 打包、收集 | 俯视的行李箱或篮子，物件随拍从 1.7 倍砸下来（s18） |
| **身高刻度** | “长大”“这些年” | 门框当身高尺，强拍上换画（小孩 → 少年 → 大人），铅笔描出刻度和年份（`full_grow.py`） |
| **撕页日历** | 时间流逝、间奏 | 每拍撕走一页往左飞，窗外天色轮换，最后落下行李箱（`full_s17.py`） |
| **风物陈列** | 纯音乐段 | 每小节落下一样这首歌里的东西，重拍上盖一个 `seal` 印章（s16） |
| **大笑特写** | 情绪高点 | 两张大脸 + 放射纹，3 张头发飘动的画轮换，歌词里的字从嘴边飞走（s04） |
| **镜头上摇进夜空** | 尾奏 | 整个世界往下移，主角物件（风筝）留在画面中间，星空里出现标题（`full_s24.py`） |
| **照片活过来** | 片尾承接 | 上一镜是贴着拍立得的剪贴簿，风带揭开后，照片里的画面铺满全屏开始动（s24） |

## 镜头之间怎么切

| 切法 | 写法 | 什么时候用 |
|---|---|---|
| 风带 | 上一镜 `band_in("x", sc.g1)`，下一镜 `band_out("x")`，两边颜色一样 | 段落之间、换场景 |
| 硬切 | 不加东西，切点落在强拍或句首前 | 主歌里句与句之间、进副歌 |
| 闪白 | 最后 2 帧盖一层白色，不透明度 0.6 | 导歌冲进副歌 |
| 推进去 | 放大到某一扇窗，铺满后换组（climax 版 f4） | 从外景进到室内 |

**风带的颜色**：用下一个镜头的底色（或者它的主色）。

## 画法工具（`scripts/kit/`）

- **`typo.py`**：歌词版式，每支片子都一样，组件见 [歌词版式](歌词版式.md)。
- **`draw.py`**：画这首歌自己素材的基础件。
  - 笔：`shape`、`thick`、`circle`、`ellipse`、`rect`、`poly`、`line`、`shadow_box`、`drawable`（可描画出来的线）、`tr`（摆位置）。
  - 脸：`eyes`、`mouth`、`blush`。
  - 人：`head`、`person_front`、`person_side`、`person_back`、`bike`。
  - 天气、自然：`sun`、`moon`、`stars`、`cloud`、`tree`、`bird`、`wave`、`ripples`、`rain`、`snow`、`grass`、`flower`。
  - 通用建筑：`house`（窗可点亮）、`building`（成排的窗可点亮）、`street_lamp`、`ground`、`hills`。
- **`hd_lib.py`**：色板、文字 `T` / 竖排 `VT`、`label`、`ribbon`、`puff`（云团）、`burst`（爆炸云）、`curl`（风卷）、`leaf`、`sparkle`、`crest`（浪花）、页码 `tag`。

歌词里点名的具体东西（某座庙、某种食物、某个地标、一张车票）都在工程的 `scripts/assets/` 里新画，画完用 `asset_sheet.py` 出素材表检查。

`examples/风吹新竹/drawings/` 里有当时画的人物、道具和新竹地方道具（东门城、晒米粉架、柿饼、招潮蟹、心型石沪等），只用来参考画法：比如一座城门怎样用几块矩形和两层屋檐搭出来、一碗汤怎样画热气。
