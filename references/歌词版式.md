# 歌词版式：多彩拼贴打字

这是每支片子都不变的部分。画面随歌词重新画，歌词出现的方式始终是同一套：
- 按唱的节奏一个字一个字打出来；
- 写在画面里的某样东西上，或者用大字砸下来；
- 颜色在一组平涂色里轮换，整页看起来像贴满了贴纸、胶带和印章的拼贴本。

代码在 `scripts/kit/typo.py`。每个组件都接收 Scene、一个 id、文字（或歌词序号 `li`，自动带出文字和逐字时间）、位置，并且自己登记动画。放进 `sc.wobT(...)` 里，字会跟着轻轻抖。

## 组件

| 组件 | 样子 | 适合 |
|---|---|---|
| `typing` | 普通打字（霞鹜文楷）；`on_dark=True` 时白字墨边 | 任何一句 |
| `slam` | 站酷快乐体大字，粗墨边加硬阴影，一个字一个字砸下来，先压扁再弹起 | 副歌钩子、关键一个字、标题 |
| `label_line` | 纸标签，带硬阴影、微微倾斜，可加胶带 | 安静的一句，标签颜色按 `combo(i)` 轮换 |
| `ribbon_line` | 黑缎带从侧面拍进来，黄字写在上面 | 一段的收尾句、一句宣告 |
| `sign` | 招牌，默认竖排 | 街道、店铺、市场 |
| `couplet` | 一对红对联，先右后左 | 庙、门口、过年 |
| `chalk_board` | 黑板菜单，竖排分栏，右栏先写 | 小吃摊、教室、咖啡馆 |
| `road_sign` | 绿色高速路牌，挂在画面上方 | 公路、旅途、距离 |
| `bubble` | 漫画对话框，里面一个大字 | 喊声、“啊”“哇”这样的拖腔 |
| `seal` | 红色竖排印章，在拍点上盖下，溅出墨点 | 标题、地名、片尾 |
| `sky_write` | 一颗流星在夜空里把句子写出来 | 夜晚、愿望、名字、约定 |
| `hang_tag` | 线上挂着的纸吊牌，落下后来回晃 | 挂在街上或门口的一句 |
| `spill` | 一个个小字贴纸从某处飞出去 | 笑声、吵闹、被风吹走的话 |
| `blow_off` | 唱完之后，整句被吹出画面 | 段落之间的收场 |
| `tape` | 一条半透明胶带 | 贴照片、标签、车票 |

## 规矩

1. **一句歌词一个载体。** 同一句不要同时出现在两个地方。
2. **载体要和画面呼应。** 庙配对联，公路配路牌，夜空配流星写字。不要用底部字幕条。
3. **按唱的节奏打字。** 用 `li` 时，逐字时间来自 `music.syllables()`，每个字比唱早 0.04 秒出现；不做 KTV 那种逐字变色。
4. **唱的时候必须完整可读。** 句子至少停到唱完，`blow_off` 只能在唱完之后用。
5. **大字要省着用。** `slam` 一个镜头最多一处，留给钩子和关键字。
6. **颜色轮换。** 相邻的标签用 `combo(i)` 依次取色，不要两张挨着的标签同一个颜色。
7. **拼贴质感来自小细节。** 硬阴影、胶带、印章溅出的墨点、标签的微倾斜，都已经做在组件里，不要去掉。
8. **深色底上换写法。** 夜景、饱和的底色上，用 `typing(on_dark=True)`，或者把字放在标签、缎带上。
9. **字体**：句子用霞鹜文楷（WK）；大字、印章、缎带用站酷快乐体（KL），繁体片自动换成 Chiron GoRound TC。所有字都要在字体子集里，构建时会检查。

## 写法示例

```python
import typo
svg = (typo.label_line(sc, "a", 4, 960, 190, 72, i=0)                     # 第 4 句写在纸标签上
       + typo.slam(sc, "t", "风吹新竹", 960, 560, 230, [164.67, 164.97, 165.27, 165.57])
       + typo.couplet(sc, "cp", 2, xr=1712, xl=218, y=236)                   # 第 2 句写在对联上
       + typo.seal(sc, "se", "风城", 1396, 765, 56, 167.83))
body = ... + sc.wobT(svg) + ...
```
