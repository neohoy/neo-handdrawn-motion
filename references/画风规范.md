# 画风规范：逐帧手绘

一支片子只用这一种动画风格。分成两部分：
- **画法和歌词版式**：每首歌都一样。
- **画什么**：每首歌按歌词重新设计，见 [歌词转画面](歌词转画面.md)。

## 固定的画法

### 线和面

- **墨线**：1920 宽画布上统一 7 px（`LW`），颜色 `INK #191919`，圆角接头。粗的肢体、围巾、发丝、道路用 `thick()`：先画一条更粗的墨线，再在上面压一条彩色线。
- **平涂**：只用纯色填充，不用渐变。阴影一律是错开 10–14 px 的硬墨色块（`shadow_box()`，以及 `T(..., shadow=)`）。
- **线条抖动（boil）**：每个镜头有三套 `feTurbulence` 滤镜，种子每 1/12 秒轮换一次（`boil()` 自动做）。画面元素包在 `sc.wob(...)` 里（抖动幅度 6），文字包在 `sc.wobT(...)` 里（幅度 3.2，保证认得清）。
- **纸张颗粒**：每个镜头盖一层 `sc.grain(op)`。浅底用 0.45–0.9，深底用 0.35。颗粒滤镜最后已经和元素自身像素做了 `feComposite in`，不要删，删了会漏到别的镜头上。
- **除了光晕和颗粒层，所有元素都有墨线。**

### 动作节奏

- **画出来的动作一律 12 fps（一拍两张）**：补间用 `q(ease, dur)` 把进度量化到 1/12 秒；整张换画用 `cycle()`；抖动和摆动用 `jitter()`。
- **只有“摄影机效果”可以平滑**：最后的淡出、闪白。
- **落地要有压扁回弹**：砸字、印章、东西落地时，先压扁 1/12 秒，再 `back.out` 弹回。
- **快速移动加速度线**，不要做运动模糊。

### 人物的画法

`draw.py` 里的人都是参数化的，所以每首歌可以画自己的角色。
- **正面** `person_front`：
  - 头半径 r，脚落在 `cy + r·(2.9 + 1.5·legs)`；
  - `legs` 控制腿长，小孩用 0.6，大人用 1.3；
  - 发型有 bob / long / short / bun / cap 五种；
  - 表情有 open / closed / happy / wink / sad，嘴型有 smile / laugh / o / flat / sad；
  - 手势有 down / up / wave / hold；
  - `wind` 控制头发和围巾被吹向哪边、吹多大。
- **侧面走路** `person_side`：面朝左，用 `legsA` / `legsB` 两张腿的画轮换；可以背书包、拖行李箱、挎包。
- **背影** `person_back`，以及**骑单车** `bike`。
- **同一个角色的不同年龄**：保持发型、标志色和配饰不变，只改头半径和腿长。

## 每首歌重新定的

- **母题和方向**：全片反复出现、带着画面走的东西，以及它的方向。《风吹新竹》是风，从右往左吹，所以头发、围巾、树叶、行人都朝左。新歌按自己的歌词定，也可以没有方向性的母题。
- **角色**：长相、衣服、标志色都从歌词推出来。
- **道具和地点**：歌词点名的都新画，地方特色先查资料再画。
- **颜色节奏**：按段落排底色，相邻段拉开。《风吹新竹》的顺序是：米白纸 → 夕阳橙 → 黄 → 海岸青 → 暮紫 → 夜蓝 → 副歌玫红 → 千窗夜蓝 → 暖黄 → 米白纸。

## 颜色

下面是基础色板，歌词版式的标签轮换也从这里取色。每首歌可以按需要加颜色，但要保持平涂、饱和、和墨线搭配。

## 歌词

歌词版式是这个技能的招牌，规则单独写在 [歌词版式](歌词版式.md)。简体和繁体全片只用一种，由 `mv.json` 的 `script` 决定，生成镜头时自动转换。

## 不要做

- 照片、写实贴图、渐变光效、科技感 HUD。
- KTV 逐字变色、底部字幕条、整屏摇晃、大幅推拉镜头。
- 简繁混用、整片一个底色。
- 把另一首歌的角色、道具或画面直接搬过来。
- 和歌词无关的通用画面，比如一颗心、一个地球、一束光线。
