# 动效写法与避坑

## 时间约定

- **两种时间**：`mv.json` 和 `music.py` 用的是**全曲时间**（秒）；每个镜头的 GSAP 时间轴从 0 开始，是**镜头内时间**。在 Python 里一律用全曲时间，写进 JS 之前用 `sc.L(t)` 转换。
- **逐字时间**：`music.syllables(i)` 把第 i 句的字均匀铺在演唱时长的前 72%，每个字提前 0.04 秒出现。歌词数据比较粗时，宁可提前，不要落后。
- **对拍**：
  - 用 `music.downbeats()` 找强拍，`music.beats()` 找每一拍，`music.half_beats()` 找半拍。
  - 颜色切换、砸字、印章盖下这类瞬间动作，放在重拍上，误差 0 毫秒。
  - 连续动作（走路、飞行）按秒算，不追拍。
- **换组时间**：放在下一句开唱前约 0.2 秒。镜头之间的切点也一样，可以落在强拍上，也可以落在句首前。

## Python 场景 API（`scripts/kit/scene.py`）

| 写法 | 作用 |
|---|---|
| `sc = Scene(id, prefix, bg, fonts)` | 从 `mv.json` 读出这个镜头的起止时间。`prefix` 是元素 id 的前缀，整片里不能重复 |
| `sc.chars(key, text, x, y, size, fam, fill, …)` 底层排字（歌词请优先用 `typo.py` 的组件） | 每个字一个 `<g id=prefix-key{i}>`（默认隐藏），返回 SVG 和每个字的弹出原点；`vertical=True` 是竖排 |
| `sc.line(key, i, x, y, size, …)` | 第 i 句歌词，排版并自动安排逐字弹出 |
| `sc.pop_chars(key, origins, times)` | 按给定时间逐字弹出 |
| `sc.blow_chars(key, n, origins, t)` | 从 t 开始，整句被风吹到左边去 |
| `sc.band(name, color)` + `band_in / band_out / band_through` | 风带转场。`band_in`：在本镜头结束时刚好盖满画面；`band_out`：下一个镜头开场时揭开；`band_through`：在镜头中间穿过一次，在 `t_mid` 后的 1/12 秒内盖满，组就在这时切换 |
| `sc.group(name, svg, op)`、`sc.wob()`、`sc.wobT()`、`sc.grain()`、`sc.page()` | 分组、抖线、颗粒、页码 |
| `sc.show / sc.hide(选择器列表, t)` | 瞬间显示或隐藏 |
| `sc.js.append("…")` | 直接写 GSAP 语句；时间用 `sc.L()` 转成镜头内时间 |

## JS 小工具（每个镜头都有）

| 函数 | 作用 |
|---|---|
| `q(ease, dur)` | 把缓动量化成 12 fps，所有画出来的动作都用它 |
| `pop(sel, t, origin, dur, ease, rot)` | 标准的手绘弹出（从 0.3 倍放大 + 转正） |
| `cycle(ids, t0, t1, step, order)` | 整张画轮换：走路换腿、头发飘动 |
| `jitter(sel, t0, t1, step, states)` | 只用 `set` 的抖动和摆动，跳帧也安全 |
| `bump(sel, t, origin, s)` | 落在拍点上的一下放大回弹 |
| `drawOn(sel, t, d)` | 描边画出来，路径要带 `pathLength="1" stroke-dasharray="1 1" stroke-dashoffset="1"` |
| `blowAway(sel, t, origin, dx, rot)` | 被风吹走（往左飞出） |
| `bandIn / bandOut` | 风带转场的底层函数 |

## GSAP 在“按时间跳帧”下的坑（必须遵守）

HyperFrames 渲染时，多个 worker 会乱序跳到任意时间点截图。GSAP 的 `svgOrigin` 带内部状态，有些写法跳帧后结果会变。《风吹新竹》里因此出过两次跑位：机车开出了路面，吊牌低了 35 像素，而且 `hyperframes check` 都没查出来。

1. **一个元素只用一个变换原点。** 同一个元素的所有补间，`svgOrigin` 写同一个点。
2. **大位移不要配 `svgOrigin`。** 沿路径行驶、飞出画面这类动作，二选一：
   - 直接补间 `attr: { transform: "translate(x y) rotate(r) scale(s)" }` 字符串，关键帧在 Python 里算好；
   - 拆成两层：外层只做 x/y 位移（不写 `svgOrigin`），内层做旋转和缩放。
3. **延后开始的补间不要配 `immediateRender: false` 再加 `svgOrigin`。** 需要延后摆动时，改成补间 `transform` 属性（如吊牌摆动：`attr: { transform: "rotate(7 430 -20)" }`）。
4. **安全的写法**：同一原点的多段补间、第一段用 `to`、只用 `set` 的 `jitter` 和 `cycle`、纯 x/y/opacity 补间。
5. **同一元素有多个 `fromTo` 时**，除了最早的那个，其余都要加 `immediateRender: false`（lint 会报 `gsap_repeated_fromto_without_baseline`）。
6. **压扁和位移分两层**：落地时外层管下落（y），内层管压扁（只用 `to`，不用 `fromTo`）。
7. **不要用 `Math.random()` 和 `Date.now()`。** 随机效果在 Python 里用固定种子的 `random.Random(seed)` 生成好。
8. **JS 里别写 Python 变量。** 在 f-string 里拼 JS 时，`{-120 + 60 * i}` 这样的表达式要先在 Python 里算出结果，否则会变成 JS 的 `ReferenceError`，整个镜头的时间轴都会失效。症状是快照里画面停在初始状态，风带盖满全屏。

## HyperFrames 的坑

- **渲染必须加 `--experimental-fast-capture=false`。** 默认的快速截帧会让画面比时间码早约 0.15 秒，对拍全歪。`tools/render.py` 已经加好。
- **项目根目录只能有一个入口 `index.html`。** 备份的入口不要放在根目录，否则 lint 会报 `multiple_root_compositions`。
- **未激活的镜头只是被设成 `visibility: hidden`**，`feTurbulence` 这类自己生成像素的滤镜照样会画出来。颗粒滤镜最后的 `feComposite in` 就是为这个加的。
- **镜头起点落在两帧之间时**，第一帧是 `ceil(start × 30)`。抽查转场时按这个取帧，不然会误以为没切过去。
- **`check` 或 `snapshot` 偶尔报 `Navigation timeout of 10000 ms`**：通常是机器负载高。加上环境变量 `PRODUCER_PAGE_NAVIGATION_TIMEOUT_MS=90000` 再跑一次。
- **一个页面挂的镜头越多，截帧越慢**：《风吹新竹》24 个镜头整体渲染约 3 帧/秒，共 36 分钟；改成每段 4 个镜头的分段渲染后只要 11.4 分钟。所以 `render.py` 默认分段渲染。分段要求切点在整帧上，先运行 `assemble.py P --snap`，再重建镜头。

## 构建的坑

- **改了脚本，要重建所有用到它的镜头。** 一个脚本带参数生成多个镜头时（如副歌一、二的“长大”），改完要把每个变体都重建。《风吹新竹》简体版就漏建了第二遍副歌那一镜，成片里两遍副歌的画面不一致，直到逐帧对比繁体版时才发现。最稳的做法是：全片渲染前跑一次 `build.py P`，不带参数，重建全部镜头。
- **简繁转换要按整句转，不能逐字转。** “里”单独转换时会保持“里”；放在“心里”里才会转成“裡”，放在“公里”里则保持“里”。`text.py` 和 `fonts.py` 都是按整句转换的；自己写工具时也要这样，否则字体子集会缺字。
- **`hyperframes init` 默认会从 GitHub 同步本机全局安装的 HyperFrames 技能**：`new_project.py` 已经用 `HYPERFRAMES_SKIP_SKILLS=1` 关掉了这一步。

## 检查清单（每个镜头）

1. `build.py` 能跑通：没有缺字，没有 Python 报错。
2. `preview.py` 截 3–6 帧，至少覆盖：开场、每组中间、歌词写完时、结尾。逐张看：
   - 字有没有被挡住；
   - 构图是不是太空；
   - 东西有没有露在画面边上；
   - 有没有方向不对的（风必须从右往左吹）。
3. 全片拼好后跑 `npx hyperframes@0.8.123 check .`，要求 0 错误。警告逐条看过：首尾相接的补间重叠可以忽略，对比度不足要改。
4. 渲染后看 `renders/<name>-cuts.jpg`，确认每处转场都接上了。
