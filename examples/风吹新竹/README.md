# 示例：《风吹新竹》（hoy neo）

这些是全曲版里挑出来的场景构建脚本，**只作参考，不能直接运行**：时间、歌词序号、镜头 id 都绑定那首歌，完整工程不随技能发布。写新场景时照着它们的套路改，不要整段复制。

`drawings/` 里是这首歌当时画的人物（白衬衫黄围巾的主角、扎发夹的朋友）、道具（庙、骑楼、列车、咖啡杯、日历、行李箱……）和新竹地方道具（`local/hsinchu.py`）。它们属于《风吹新竹》，新歌不能直接搬用；需要类似的东西时，参考它们的画法，按新歌的歌词重新画到新工程的 `scripts/assets/`。

| 文件 | 看点 |
|---|---|
| `full_s02.py` | 一个场景两组画面 + 风带转场；影子随时间拉长；人物走路换腿；灯笼按机车经过的时间点亮并吸附到半拍；歌词写在竖排招牌上 |
| `full_s11.py` | 四格漫画：一句歌词一格，格子在句首前砸进来；裁切 `clipPath` 里放各格画面 |
| `full_grow.py` | 同一个脚本带参数生成两个镜头（副歌一、二各一个）；强拍上换画（小孩 → 少年 → 大人）+ 铅笔刻度 |
| `full_s17.py` | 撕页日历：每拍撕走一页；窗外天色按拍轮换；行李箱落地用“外层位移 + 内层压扁”两层结构 |
| `full_s24.py` | 尾奏：整个世界往下移来模拟镜头上摇；风筝飞走用不带 svgOrigin 的外层；最后纸带合上 + 淡出 |
| `build_f2.py` | 机车沿路面曲线行驶：按曲线采样关键帧，直接补间 `transform` 属性字符串（避开 GSAP svgOrigin 的坑） |
| `build_f3.py` + `city.py` | 夜街千窗：主角走过时，窗按半拍一簇簇亮起；同一画面靠环境变量生成副歌一、二的变体（旧做法，新工程改用脚本参数） |

当时的工程还没有 `mv.json`，`cut.py` 里的镜头表和 `HD_CUT` 变量是旧写法；新工程统一用 `mv.json` 的 `scenes` 和 `Scene.page()`。
