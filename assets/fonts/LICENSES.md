# 字体许可

- `JetBrainsMono-400-normal-latin.woff2` — JetBrains Mono（JetBrains），SIL Open Font License 1.1，拉丁子集。用途：页码、编号、数字。
- `InstrumentSerif-400-italic-latin.woff2` — Instrument Serif Italic（Instrument），SIL Open Font License 1.1，拉丁子集。用途：手写感署名。

中文字体不随技能分发，由 `scripts/tools/fonts.py` 按每首歌用到的字从 Google Fonts 取子集，都是 OFL 1.1：站酷快乐体 ZCOOL KuaiLe（简体大字）、Chiron GoRound TC（繁体大字）、霞鹜文楷 LXGW WenKai TC（句子）。
